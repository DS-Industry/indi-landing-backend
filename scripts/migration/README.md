# Postgres Migration Script

One-off data migration utility from legacy Oracle schema to Postgres schema.

## Features

- batch processing
- insert mode with target-generated ids
- checkpoint resume
- dry-run mode
- JSON report with migrated/failed counters

## Command

```bash
npm run migration:postgres
```

## Required environment variables

Source (Oracle):

- `LEGACY_DB_HOST`
- `LEGACY_DB_PORT`
- `LEGACY_DB_USERNAME`
- `LEGACY_DB_PASSWORD`
- `LEGACY_DB_SID`

Target (Postgres):

- `POSTGRES_HOST` (or `DB_HOST`)
- `POSTGRES_PORT` (or `DB_PORT`)
- `POSTGRES_USER` (or `DB_USERNAME`)
- `POSTGRES_PASSWORD` (or `DB_PASSWORD`)
- `POSTGRES_DATABASE` (or `DB_DATABASE`)

Script options:

- `MIGRATION_DRY_RUN=true|false` (default `false`)
- `MIGRATION_BATCH_SIZE=500` (default `500`)
- `MIGRATION_CHECKPOINT_FILE=...` (default `scripts/migration/.checkpoint.json`)
- `MIGRATION_REPORT_FILE=...` (default `scripts/migration/.report.json`)
- `MIGRATION_REGENERATE_IDS=true|false` (default `true`)
- `MIGRATION_CARD_TIER_ID=200` (default `200`)
- `MIGRATION_ORGANIZATION_ID=1` (default `1`)

## Recommended order

The script already migrates tables in FK-safe order:

1. `CRDCLIENT`
2. `CRDCARD`
3. `CRDCARD_TYPE`
4. `INDIAN_CLIENT_PSW`
5. `INDIAN_EMAIL_CODE`
6. `INDIAN_SUBSCRIBE`
7. `INDIAN_PACK_MIN`
8. `INDIAN_PACK_USAGE`
9. `INDIAN_REMAINS_PACK`
10. `INDIAN_INVITED_CODE`
11. `INDIAN_INVITED_CODE_USAGE`

## Notes

- Script expects Postgres tables to already exist.
- Keep quoting in table/column names if legacy uppercase names were used.
- Re-run with `MIGRATION_REGENERATE_IDS=true` requires cleanup/truncate to avoid duplicates.
- With `MIGRATION_REGENERATE_IDS=true`, ids are generated by target DB sequences (legacy ids are not copied).
- Foreign keys are remapped via in-memory old->new id maps during the run.
- Card migration enforces defaults: card tier `200` and organization `1`.
- If `LTYCard` table exists in `public` schema, script also applies these defaults there after migration.
- `CRDCLIENT` and `CRDCARD` are migrated only for clients present in `INDIAN_CLIENT_PSW`.
